# Simple React App

A minimal React + Vite starter app with a single test page.

## Setup

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Project structure

```
simple-react-app/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx      # entry point
    ├── App.jsx       # root component
    ├── TestPage.jsx  # the test page (counter + input demo)
    └── index.css     # styles
```

## Build for production

```bash
npm run build
npm run preview
```
